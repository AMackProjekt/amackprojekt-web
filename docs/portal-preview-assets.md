# Portal preview assets

Captured September 17, 2026 from the actual staff page components in
`AMackProjekt/projekt-enterprise`, commit `6c66ded255e1af745eb3bb37790c2b78f908a78f`.

The capture harness renders the staff layout and dashboard, caseload, trainings,
and calendar pages with local providers. Authentication and backend calls are
stubbed; participant names, roster counts, and staff identity are demo values.
Existing sample content within the source pages remains visible. No production
participant records or connected-service data were accessed for these assets.
Every capture includes a visible Product Preview / Demo Data label.

Files: `public/brand/portal-{dashboard,caseload,learning,coordination}.webp`.
The 30-second `amp-portal-intro.mp4` retains the existing 10-second AMP brand
opening, followed by five seconds per actual portal screen with fade transitions.
These are screen captures in an edited montage, not recordings of live backend
operations. The website provides chapter selection and a text introduction.

Screens are WebP, 1280 pixels wide. Video is H.264, 1280 x 720, 24 fps, with MP4
fast-start metadata. It loads only when the visitor opens the player.
